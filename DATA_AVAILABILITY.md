# Data and code availability

This repository provides analysis code, configuration examples, deidentified aggregate figure inputs, final tables and final figures associated with the dissertation.

The participant-level clinical and genotype data are controlled-access GENDEP research data supplied for the MSc project and cannot be redistributed. The repository excludes participant identifiers, individual genotype calls, clinical records, participant-level polygenic scores, ancestry probabilities, resampling assignments and held-out predictions. Controlled execution requires appropriate authorisation and access to the fixed external resources.

Public GWAS summary statistics, GenoPred, PRS-CS, Ensembl and their reference resources must be obtained from their original providers and remain subject to their respective access and reuse terms.

`results/figure_data/` contains release-safe aggregate plotting inputs. The participant-level ancestry probabilities used for Supplementary Figure S4 are excluded; only the committed final PNG and aggregate summary are provided. `results/table_data.yml` contains the unrounded machine-readable dissertation tables. Neither location contains raw genotype data or participant-level clinical records.
